## Sitio web

El catálogo visual está en [`docs/index.html`](docs/index.html). Para publicarlo con GitHub Pages, entra en **Settings → Pages**, selecciona **GitHub Actions** como fuente de despliegue y ejecuta o espera el flujo `Deploy GitHub Pages` incluido en `.github/workflows/pages.yml`.

## Cómo usarlo

1. Elige una tecnología en el catálogo.
2. Consulta la hoja completa o la referencia de un minuto.
3. Copia los ejemplos y pruébalos en un proyecto local.
4. Revisa `projects/` para practicar con aplicaciones pequeñas.

## Contribuir

Puedes abrir un issue o pull request para corregir un ejemplo, añadir una tecnología o mejorar una explicación. No subas claves, tokens ni archivos `.env`.
