# Programming Cheat Sheets

Colección de hojas de trucos prácticas en español para consultar comandos, sintaxis y conceptos esenciales de programación.

## Contenido

| Tecnología | Archivo | Temas principales |
|---|---|---|
| Python | [Ver hoja](python/cheat-sheet.md) | Sintaxis, colecciones, funciones, archivos y errores |
| JavaScript | [Ver hoja](javascript/cheat-sheet.md) | Variables, arreglos, objetos, DOM y asincronía |
| Git | [Ver hoja](git/cheat-sheet.md) | Commits, ramas, remotos y recuperación |
| CSS | [Ver hoja](css/cheat-sheet.md) | Selectores, Box Model, Flexbox, Grid y responsive |

## Cómo usar este repositorio

1. Abre la carpeta del lenguaje que deseas consultar.
2. Lee el archivo `cheat-sheet.md` directamente en GitHub.
3. Copia y adapta los ejemplos a tus proyectos.

## Contribuciones

Las contribuciones son bienvenidas. Puedes proponer correcciones, nuevos ejemplos o una hoja para otro lenguaje mediante un issue o pull request.
