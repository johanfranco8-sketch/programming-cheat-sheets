# Mini proyectos

Estos proyectos sirven para practicar después de leer cada hoja de trucos.

| Proyecto | Tecnología | Qué practicar |
|---|---|---|
| [Contador de palabras](python/contador-palabras.py) | Python | Funciones, diccionarios, entrada de texto y ordenamiento |
| [Lista de tareas](javascript/lista-tareas.html) | HTML, CSS y JavaScript | DOM, eventos y `localStorage` |
| [Tarjeta de perfil](html-css/tarjeta-perfil.html) | HTML y CSS | Semántica, Flexbox, responsive design y variables CSS |

## Ejecución

- Python: ejecuta `python contador-palabras.py` dentro de `projects/python`.
- Proyectos web: abre el archivo HTML en el navegador o usa la extensión Live Server de VS Code.
